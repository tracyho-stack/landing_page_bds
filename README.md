# Vinhomes Grand Park Landing Page

## Mục tiêu

Tạo một landing page đơn giản để quảng cáo dự án bất động sản **Vinhomes
Grand Park tại Thành phố Thủ Đức**.

## Công nghệ

-   HTML5
-   CSS3
-   Bootstrap thông qua CDN
-   JavaScript thuần (Vanilla JavaScript)
-   Không sử dụng backend
-   Không sử dụng framework frontend khác

## File đầu ra bắt buộc

Mã nguồn chính phải được lưu tại:

`index.html`

Landing page phải có thể mở trực tiếp trên trình duyệt và hiển thị đầy
đủ giao diện.

## Cấu trúc nội dung

Trang gồm: 1. Header / Navbar 2. Hero Section 3. Features Section 4.
Footer

Chi tiết yêu cầu xem tại `REQUIREMENTS.md`.

## Nguyên tắc

-   Thiết kế đơn giản, hiện đại, phù hợp lĩnh vực bất động sản cao cấp.
-   Responsive trên desktop và mobile.
-   Màu nền chủ đạo: `#f2f2f2`.
-   Màu chữ/điểm nhấn chủ đạo: `#2d2d86`.
-   Chỉ render HTML, CSS và JavaScript.
